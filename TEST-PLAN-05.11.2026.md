# «Три гвоздя» — план проверки входа и синхронизации

Ветка: `FINAL-05.11.2026`. Версия `FINAL-04.11.2026` и установленное iPhone-приложение остаются неизменными.

## Что подготовить для теста
1. Отдельный тестовый HTTPS-адрес, не заменяющий действующий GitHub Pages. Сервер Node.js 22+ должен обслуживать и интерфейс, и API на одном домене.
2. Хостинг с **постоянным закрытым диском**. Настроить `DATA_DIR` для аккаунтов/задач, HTTPS и резервное копирование серверных данных. Не публиковать `db.json`.
3. Подключить GitHub-ветку `FINAL-05.11.2026` к тестовому размещению. После согласования платформы создать отдельную тестовую учётную запись.
4. Проверить серверные тесты `node --test sync/sync.test.cjs`, синтаксис JavaScript и реально доступные по HTTPS файлы `index.html`, `sync/client.js`, `sync/client.css`, `sync/merge.js`.
5. Для первого испытания ноутбук и телефон открывают **один новый тестовый HTTPS-адрес в браузере**. Собранный Windows `.exe` тестируется отдельно: в Electron нужно настроить адрес API, поскольку схема `nails://` не даёт его автоматически.

## Проверка на телефоне и ноутбуке
1. Телефон: открыть тестовый адрес в браузере. Дождаться приветствия, нажать «Начать работу», затем «Создать аккаунт». Ввести тестовые логин и пароль.
2. На телефоне создать «ТЕСТ: задача с телефона» с датой/временем.
3. На ноутбуке открыть тот же тестовый адрес, выбрать «Войти», ввести те же логин/пароль. Убедиться, что появилась телефонная задача.
4. На ноутбуке добавить «ТЕСТ: задача с ноутбука». Вернуться в телефон — проверить появление новой задачи.
5. Изменить дату, приоритет и отметку выполнения на одном устройстве; проверить на другом. Проверить перенос и удаление.
6. Отключить интернет на телефоне, создать задачу, затем включить интернет. Проверить, что она появилась на ноутбуке без повторной авторизации.
7. Закрыть и открыть приложение на каждом устройстве. Проверить сохранённый вход и наличие задач.
8. Создать JSON-копию. Проверить импорт файла и синхронизацию восстановленных задач.
9. Только на **тестовом аккаунте**: проверить предупреждение «Очистить все данные». Подтвердить, затем убедиться, что на обоих устройствах задачи удалены, но аккаунт остаётся активен.
10. Создать второй тестовый аккаунт и проверить, что он не видит задач первого. Проверить неправильный пароль и конфликты одновременного редактирования.
11. После браузерных проверок отдельно испытать установщик Windows и сохранение файла в `Документы/Три гвоздя/3-gvozdya-data.json`.

## Критерий готовности
Одинаковые задачи на телефоне и ноутбуке после входа в один аккаунт, двусторонние изменения, работа без интернета с последующей синхронизацией, отсутствие потерь и пересечения чужих аккаунтов. Тест должен быть выполнен на реальных устройствах.

## Текущий статус
Серверный и клиентский код добавлены, но работающий сервер и тестовый HTTPS-адрес ещё **не развёрнуты**. Реальная межустройственная синхронизация **не подтверждена**. Для продолжения надо выбрать площадку размещения с постоянным хранилищем. Не удалять действующее iPhone-приложение и не вводить в тест реальные задачи до резервного копирования.
